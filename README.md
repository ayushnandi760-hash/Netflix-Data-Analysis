# Netflix Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset.

The objective is to identify patterns, trends, and insights related to Netflix content using data analysis and visualization techniques.

## Dataset

Netflix Movies and TV Shows Dataset from Kaggle.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Project Workflow

### 1. Data Inspection

* Loaded the dataset
* Checked shape, data types, missing values, and duplicates

### 2. Data Cleaning

* Handled missing values
* Removed duplicates
* Fixed data types

### 3. Exploratory Data Analysis

* Movies vs TV Shows
* Top content-producing countries
* Content growth over time
* Rating distribution
* Release year analysis

### 4. Visualizations

* Bar Chart
* Line Chart
* Histogram
* Scatter Plot
* Pie Chart
* Heatmap

## Key Insights

* Movies dominate Netflix's content library.
* Netflix experienced rapid growth after 2015.
* Most content was released after 2000.
* A few countries contribute the majority of titles.
* Mature audience ratings are the most common.

## Conclusion

The analysis revealed significant growth in Netflix content over recent years and highlighted important trends in content type, ratings, and country-wise production.
